# Model Evaluation & Metrics

This directory will contain validation scripts, benchmark evaluations, and reporting utilities.

## Metrics & Outputs
* Classification Reports: Precision, Recall, F1-Score (macro & weighted).
* Confusion Matrices: Visualization of misclassified feedback sentiments and categories.
* Error Analysis: Exporting edge cases and ambiguous student comments for further linguistic inspection.
* Benchmark Comparisons: Traditional ML (Logistic Regression, SVM, Naive Bayes) vs. Deep Learning (LSTM, BiLSTM) performance.
