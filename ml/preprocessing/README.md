# Text Preprocessing Modules

This directory will contain reusable NLP preprocessing scripts for student feedback text.

## Planned Modules
* Text cleaning: lowercasing, HTML/special characters removal, URL & email masking.
* Tokenization & Stopword removal (NLTK / spaCy).
* Lemmatization and part-of-speech (POS) tagging.
* Contraction expansion and spelling correction for student comments.
* Vocabulary construction and embedding matrix loaders.
