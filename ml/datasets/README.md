# Datasets

This directory holds raw, processed, and benchmark datasets for student feedback intelligence.

## Organization
* `raw/`: Unprocessed student feedback surveys, course evaluation text files, and institutional forms.
* `processed/`: Cleaned, tokenized, and labeled data splits (`train.csv`, `val.csv`, `test.csv`).
* `external/`: Any third-party benchmark datasets (e.g., educational review datasets).

> **Note**: Datasets will be ingested during the data preparation milestone.
