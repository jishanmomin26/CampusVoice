# Machine Learning & NLP Pipeline

This directory contains the machine learning, deep learning, and natural language processing pipelines for **CampusVoice**.

## Subdirectory Structure

* **`datasets/`**: Raw feedback text, processed training/validation splits, and survey corpora.
* **`notebooks/`**: Jupyter notebooks for exploratory data analysis (EDA), data cleaning trials, and model prototyping.
* **`preprocessing/`**: Modular Python modules for text normalization, regex cleaning, tokenization, lemmatization (spaCy/NLTK), and feature extraction.
* **`training/`**: Scripts and pipelines for training sentiment analysis, topic modeling, and feedback categorization models.
* **`evaluation/`**: Performance validation scripts, metrics calculators (precision, recall, F1, accuracy), and confusion matrix generators.
* **`models/`**: Serialized model binaries, vectorizers (TF-IDF/Word2Vec/FastText), and neural network checkpoints.
