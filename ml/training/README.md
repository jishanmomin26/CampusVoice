# Model Training Pipelines

This directory will contain Python scripts and pipelines for training machine learning and deep learning models.

## Planned Pipelines
* **Sentiment Analysis**: Multi-class sentiment classifier (Positive, Neutral, Negative) using scikit-learn baseline and TensorFlow/Keras LSTM architectures.
* **Aspect / Category Classification**: Categorization of feedback into institutional departments (e.g., Academics, Infrastructure, Administration, Hostel, Sports).
* **Word Embeddings**: Training custom Word2Vec/FastText embeddings using Gensim on institutional feedback data.
* **Topic Modeling**: Unsupervised discovery of emerging campus issues using LDA or BERTopic.
